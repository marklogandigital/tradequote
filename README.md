# TradeQuote

A Next.js 14 application for generating quick quotes for trade jobs.

## Features

- Clean, minimal homepage with TradeQuote branding
- Quote builder with real-time calculations
- Automatic calculation of area, labour costs, material costs, and total
- Responsive design optimized for mobile and desktop

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/page.tsx` - Homepage route
- `app/quote/page.tsx` - Quote builder page with form and calculations
- `app/layout.tsx` - Root layout component
- `app/globals.css` - Global styles with Tailwind CSS

## Technologies

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- React 18
